# Script Reference

## Directory Layout

```
scripts/
  # Core C++ analysis (run via ROOT)
  v2_eff_correction.cpp        # v2 with TPC efficiency correction
  v2_no_eff_correction.cpp     # v2 without efficiency correction (primary path)
  v2_no_eff_correction_alt.cpp # Alternative v2 method (unused)
  coal_preprocess.cpp          # Project 2D histograms to 1D with rapidity cut
  draw_TOF_eff_2.cpp           # Calculate TOF detector efficiency

  # ROOT class extensions
  ExtendedTProfile.cpp/.h      # TProfile subclass with SetSumw2()
  Efficiency.h                 # Template header for efficiency lookup

  # Python analysis
  TPC_eff.py                   # Fit TPC efficiency from embedding
  fit_v2.py                    # Extract Lambda/Lambdabar v2 via invariant mass fits
  plot_v2_new.py               # Main plotting: coalescence ratios, delta_v2, Lambda comparison
  plot_v2_isobar.py            # Isobar (Ru vs Zr) comparison plots
  plot_all.py                  # Energy-scan overlay plots
  combine_sys.py               # Combine systematic uncertainties
  generate_paper_plots.py      # Final publication-quality figures

  # Python utilities
  data_point.py                # DataPoint class (value + stat/sys errors, arithmetic)
  measurement.py               # Weighted average of multiple measurements
  simple_profile.py            # TProfile-like class for Python (rebin, merge, divide)

  {energy}/Efficiency.cpp      # Generated by TPC_eff.py

```

## C++ Scripts: Detailed Behavior

### `coal_preprocess.cpp`
Called internally by the v2 scripts when the input ROOT file contains 2D histograms (`hpiplus_EPD_v2_y_pt_1`). Projects $v_2(y, p_T)$ to $v_2(p_T)$ using the rapidity cut from config. Also extracts TOF efficiency and event plane resolution profiles.

### `v2_no_eff_correction.cpp`
The primary v2 extraction script. Arguments (passed via ROOT macro call):
1. Input ROOT file path
2. Output CSV path
3. `eta_cut` (rapidity acceptance)
4. `pt_lo`, `pt_hi` (pT/nq integration bounds)
5. `EPD_method` (e.g., "2nd")
6. `use_2D` (0 or 1)
7. `use_mT` (0 or 1)
8. Optional: `sys_tag` for special systematics

Workflow:
1. If `use_2D=1`, calls `coal_preprocess.cpp` to project histograms
2. Reads TPC and EPD v2 profiles for each particle species and centrality
3. Integrates $v_2(p_T/n_q)$ over the configured range
4. Writes per-centrality CSV with columns for each particle's v2 and error
5. Writes resolution CSV

### `v2_eff_correction.cpp`
Same as above but additionally:
- Loads the compiled Efficiency library
- Calls `draw_TOF_eff_2.cpp` to get TOF efficiency
- Weights each pT bin by `1/eff(pT)` when computing the v2 integral

### `draw_TOF_eff_2.cpp`
Reads generated vs. selected proton spectra from embedding data, computes TOF acceptance × efficiency using ROOT's `TEfficiency`, outputs `TOFEfficiency.root`.

## Python Scripts: Detailed Behavior

### `TPC_eff.py`
Reads 54 embedding ROOT files (9 centrality bins x 6 particle species) per energy. For each:
1. Extracts matched/total pT and (pT, eta) histograms
2. Fits 1D efficiency $\epsilon(p_T)$ with a parametric function using iminuit
3. Fits 2D efficiency $\epsilon(p_T, \eta)$
4. Writes fitted parameters into `Efficiency.cpp`
5. Saves QA plots to `plots/QA/`

### `fit_v2.py`
The most complex Python script (~48 KB). Extracts $v_2$ of $\Lambda/\bar{\Lambda}$ from 2D invariant mass histograms:
1. Reads ROOT histograms of $v_2$ vs $M_{inv}$ in bins of $p_T$ and rapidity
2. Fits invariant mass with double-Gaussian (signal) + polynomial (background)
3. Uses signal/background fractions to extract signal $v_2$ via the $v_2(M_{inv})$ method
4. Handles edge cases: masked signal region fits, parameter fixing/releasing
5. Performs up to 500 refits with randomized initial parameters to find global minimum
6. Outputs per-centrality/rapidity $v_2$ values to CSV

### `plot_v2_new.py`
Main plotting script (~39 KB). For each energy:
1. Reads v2 CSV and resolution CSV
2. Divides raw $v_2$ by event plane resolution
3. Merges centrality bins (e.g., bins 1-2 for low-stats energies)
4. Masks EPD results at low energies (7.7, 9.2, 11.5 GeV) where EPD is unreliable
5. Computes coalescence ratio: $(v_2(\pi^-) - 2/3 v_2(\bar{p})) / (v_2(\pi^+) - 2/3 v_2(\bar{p}))$
6. Computes $\Delta v_2 = v_2(\pi^-) - v_2(\pi^+)$ for the pion splitting
7. Reads Lambda/Lambdabar fit results and computes $\Delta v_2(\Lambda)$
8. Generates PDF plots and YAML data files for downstream consumption

### `combine_sys.py`
Takes the default YAML (sys_tag_0) and variation YAMLs (sys_tag_1, sys_tag_2):
1. For each data point, computes $\Delta = |y_{var} - y_{def}|$
2. Applies Barlow test: only counts as systematic if $|\Delta| > \sqrt{|\sigma_{var}^2 - \sigma_{def}^2|}$
3. Total systematic = $\sqrt{\sum \Delta_i^2} / \sqrt{3}$
4. Total error = $\sqrt{\sigma_{stat}^2 + \sigma_{sys}^2}$

### `generate_paper_plots.py`
Final assembly script (~43 KB). Reads all combined YAML configs and resolution data. Produces multi-panel figures with:
- v2 ratios vs centrality for all energies
- $\Delta v_2$ vs centrality
- Lambda comparisons
- Resolution plots
- Energy dependence overlays

Outputs `plots/final/report.pdf`.

## Utility Classes

### `DataPoint` (`data_point.py`)
```python
dp = DataPoint(value=0.05, stat_err=0.01, sys_err=0.005)
dp.total_error()  # sqrt(stat^2 + sys^2)
result = dp1 + dp2  # propagates errors
avg = DataPoint.average([dp1, dp2, dp3])  # weighted average
```

### `SimpleProfile` (`simple_profile.py`)
Python equivalent of ROOT's TProfile. Supports:
- Construction from histogram data (bin edges, values, errors, entries)
- `Rebin(n)` - merge n adjacent bins
- `Add(other)` - combine two profiles
- `__truediv__` - divide two profiles with error propagation
- `values()` - return (centers, values, errors) tuple

### `ParamStorage` (`param_storage.py`)
Stores fit parameters for freeze/unfreeze during multi-stage fitting.
